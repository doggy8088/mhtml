# mhtml

把 Markdown 變成**漂亮、單一檔案**的 HTML，支援 *深色模式*、`自訂 CSS` 與 [設定檔](#)。

> [!TIP]
> 只要 `mhtml README.md`，就會在瀏覽器即時預覽。

| 功能     | 旗標                 |
| :------- | :------------------- |
| 深淺主題 | `--theme dark`       |
| 自訂樣式 | `--css my.css`       |
| 目錄     | `--toc`              |
